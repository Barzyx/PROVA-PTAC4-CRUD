# Mural de Avisos da Turma

Sabe aquele mural de papel da coordenação que ninguém vê a tempo? Fiz a versão digital. Aqui dá pra publicar, editar e apagar avisos, e a lista atualiza na hora, sem precisar recarregar a página.

## API

https://jsonplaceholder.typicode.com/posts

Aviso rápido: essa API só finge que salva, então se você recarregar a página, os avisos que criou somem. É normal!

## Como rodar

```bash
npm install
npm run dev
```

Depois é só abrir o link que aparecer no terminal (normalmente `http://localhost:5173`).

## Feito com

Vite, React 18 e CSS puro.
